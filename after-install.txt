Hydra Manga TL v1 has been installed successfully.

After installation:
1. Launch Hydra Manga TL from the Start Menu or Desktop.
2. Import manga images or a folder.
3. Use the refreshed startup and import loading screens while Hydra prepares the workspace.
4. Select Translate All Pending or Translate Selected.
5. Review and correct the translated pages.
6. Collapse the filmstrip when you want more canvas space.
7. Export the completed PNG images.

- The unified OCR, translation, render, cache, cancellation, review, and manual-rerender pipeline is included in v1.
