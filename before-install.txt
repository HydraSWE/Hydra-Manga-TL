Welcome to Hydra Manga TL v1

Hydra Manga TL translates Japanese and Chinese manga pages into English using local OCR, translation, reconstruction, and review tools.

Release track:
- v1 adds safer resumable processing, provider-safe Smart Translation, large-project responsiveness, refreshed Project Home and workspace UI, searchable recent projects, multi-target output, automated schema migration and backward compatibility, editor undo/redo, reading-order controls, batch-selection polish, PDF export, and detailed GPU/native diagnostics.
- The unified OCR, translation, render, cache, cancellation, review, and manual-rerender pipeline is included in v1.
- This release uses the complete offline installer. Selectable cloud/local runtime downloads are planned for a later release and are not active yet.
- HydraMangaAi remains an optional private bridge layer when installed separately.

Important:
- Windows 10 or Windows 11 64-bit is required.
- Several gigabytes of free disk space are recommended.
- An internet connection may be required during the first local translation so model files can be downloaded.
- Cloud translation engines are opt-in and use user-supplied credentials.
- Original manga images are never modified.
- Automatic translations should be reviewed before publication.
